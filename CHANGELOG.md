# Changelog

## v0.1.0 — Initial preview

- Linux GUI for BRIDGE CAST ONE with automatic APP MIDI port detection.
- Stream Mix and Personal Mix channel levels and mutes, LINE OUT controls, selected mic controls, and live level meters.
- Device readback after setting changes, plus refresh and reconnect actions.
- **Stop mic monitoring** action to remove the mic from both device mixes while preserving USB mic capture.
- Custom Linux app icon and a HOME view based on the supplied Roland interface graphics.

This is a preview release. Some source labels and meter positions still need device-specific validation. Several visible controls are read-only, and profiles, advanced effects, SFX transfer, and firmware updates are not implemented.
